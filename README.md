# Авто под ключ до Владивостока

Калькулятор цены автомобиля из Кореи, Китая и Японии с доставкой до Владивостока.

Считает:
- пошлину для физлица по ставкам 2026 года (до 3 лет, 3–5 лет, старше 5 лет);
- утильсбор (льготный до 160 л.с. и 3 000 см³, коммерческий вручную);
- сбор за таможенное оформление;
- доставку и комиссию компании;
- текст расчёта для клиента одной кнопкой.

Демо: https://automation-333.github.io/car-calculator/

Один файл `index.html`, без сборки и зависимостей.
